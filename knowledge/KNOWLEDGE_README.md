# Lumi RAG 知識庫說明

本知識庫供 Lumi 冥想與日常放鬆助理使用，適合透過 LangChain 載入、切塊與檢索。內容涵蓋冥想、情緒壓力、睡眠、呼吸、身體不適、安全求助及 App 導覽。

每筆資料同時提供完整知識與精簡回覆。回覆採溫柔、自然、安定的語氣，保留專業感與必要的安全提醒。

## 資料欄位

`corpus.jsonl` 使用 UTF-8 編碼，每行是一筆 JSON 資料。

| 欄位 | 用途 |
| --- | --- |
| `id` | 語料識別碼；此次風格更新沿用原 ID |
| `category` / `topic` | 類別與主題 |
| `question` | 代表性問題 |
| `question_variants` | 合併前的問題變體 |
| `content` | 完整知識內容與相關限制 |
| `reply` | Lumi 精簡回覆範例，供生成時參考 |
| `tags` | 主題標籤 |
| `source` | 來源陣列，包含原始檔案／工作表／列號，或外部網址與查閱日期 |
| `source_type` | 資料來源類型 |
| `evidence_status` / `evidence_notes` | 證據狀態及適用限制 |
| `page_content` | 已組合的檢索文字，包含知識、來源、限制與精簡回覆範例 |
| `retrieval_scope` | 檢索範圍標籤；部署時仍需依類別與證據狀態確認篩選邏輯 |
| `ingestion_allowed` | 是否允許匯入；仍須套用專案額外的排除條件 |
| `reply_style` / `style_updated_at` | 回覆風格版本與更新日期 |

`reply` 用來參考語氣與篇幅，不能取代 `content` 中與使用者情境相關的專業限制或安全資訊。

### 來源類型

- `project_original`：原始專案內容，必要時經保守改寫並補充外部依據。
- `external_verified`：與已查閱來源對應的摘要，不代表所有相關療效或機制都已獲證實。
- `research_insight`：預留給問卷／訪談洞察，目前沒有此類紀錄。

外部資料主要來自 NIH／NCCIH、NHLBI、NHS、Memorial Sloan Kettering Cancer Center、臺灣衛生福利部及消防署，另含原始研究與大學研究典藏。完整網址、查阅日期與原檔指紋見 `sources.json`；逐筆引用見 `source` 欄位。

## 放入目前專案

主要語料位置：

```text
lumi-langchain/
├─ knowledge/
│  └─ lumi_rag/
│     └─ corpus.jsonl
└─ rag/
   ├─ corpus_loader.py
   ├─ build_index.py
   └─ rag_service.py
```

1. 備份目前的 `knowledge/lumi_rag/corpus.jsonl`。
2. 用本套件的 `corpus.jsonl` 替換該檔案。
3. 讓生成提示參考 `reply_style.md`，並將檢索文件 metadata 的 `reply` 帶入回覆上下文。
4. 在專案根目錄依序執行：

```powershell
python -m rag.build_index --dry-run
python -m rag.build_index
```

第一個指令驗證與切塊，不呼叫 embedding API。第二個指令使用現有 Gemini embedding 設定建立索引，會使用 API 配額。成功後重新啟動後端。

目前的 loader 會保留字串型別的 `reply`，不必另換載入器。建索引程式會建立獨立目錄，完成後切換索引設定；不必手動刪除 `chroma_db`。

不要同時匯入 JSONL、Markdown 與回覆預覽，以免重複檢索。不要匯入品質稽核檔。冥想、呼吸、穴位若由各自的 response builder 產生回覆，這些程式也需要套用同一套語氣規則。

## 內容限制

- 尚缺另 2 份專案流程／研究附件；目前依 9 份 XLSX 與 1 份流程檔整理。
- 未納入先前對話所稱的 53 份問卷與訪談洞察，不能引用為已取得的研究結果。
- 八字呼吸、箱式呼吸的兩組原回答已隔離，不在可檢索語料中。
- 未驗證的穴位生理機制保留於稽核檔，不以肯定療效呈現。穴位內容不是完整的操作教學或臨床處方。
- 固定呼吸秒數、練習分鐘數與場景搭配屬專案選項，不能宣稱為最佳療程。
- 危機與緊急醫療訊息應由獨立安全流程優先處理，不能只依賴語意檢索。
- 已檢查 JSONL 結構、來源對照、原始列涵蓋及回覆欄位；尚未完成正式 App 或向量庫的端到端效果評測。
